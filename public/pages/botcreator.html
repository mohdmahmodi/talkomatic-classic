The Bot Book

Everything about making bots, from your very first one to a whole game with points. No coding. If you can fill in a sentence, you can make a bot.

What is a bot?

A bot is a pretend person that sits in a room with its own textbox and follows rules you wrote. Everyone can see it is a bot - it wears a BOT badge with your name on it. It types letter by letter, just like a person.

Every rule is one sentence with three parts:

WHEN someone types !fish ONLY IF the checks pass (you can skip this part) DO say "You caught a fish!"

Your first bot in one minute

  1. Press Make a new bot and pick Dice.
  2. Look at its one rule: WHEN someone types !roll → DO say something.
  3. In the Test room on the right, type !roll in your box and stop typing.
  4. Watch the rule light up and the bot type in its own box. That's it, that's a bot.
  5. Change the say text. Test again. It changed instantly.
  6. Press Save my bot, then Send it to a real room.

The WHEN part (what wakes your bot up)

One important thing first: Talkomatic has no send button. So how does the bot know you finished? It waits until your last line stops changing for about 2 seconds, then reads that line. Press Enter for a new line when you want to say a new thing to the bot.

someone types !word The classic. The line must start with the command: !roll works, "please !roll" does not. Words typed after it (like !guess 7) become {word1}, {word2}... someone says a phrase Fires when the phrase is anywhere in the line. If the phrase is "pizza", then "i love pizza so much" wakes the bot up. someone says the bot's name Someone wrote your bot's name in their line. Nice for "hey FishBot". someone joins the room A person walks in. Perfect for welcome bots. (Bots never trigger other bots - only people count.) someone leaves the room A person walks out. every X minutes A clock, no person needed. Shortest is 2 minutes. In the Test room, press "Ring the timers" instead of waiting.

The DO part (what your bot does)

say The bot types a message into its box, letter by letter. This is where you use magic words (next section). Up to 300 letters. wait Pause before the next action. Timing makes jokes work: say "Shaking the 8 ball..." then wait 2 seconds, then say the answer. remember Write something down in the bot's memory, under a name you pick, like prize or coins. See the Memory section, it is the part that makes games possible. count up Add a number to a memory. Counting points, coins, visits - it is all this one action. (Add a negative number, like -5, to take points away.) pick random Put a random pick into a memory. Give it choices (rock, paper, scissors) or a number range (1-100). erase the box The bot wipes its own textbox clean. leave the room The bot stands up and goes home.

Actions run in order, top to bottom - use the little arrows to reorder them. If a rule picks a random prize and then says it, "pick random" has to be above the say.

Magic words

Write these (with the curly brackets) inside anything your bot says, checks, or remembers. The bot swaps them for the real thing at that moment:

{name} The person who woke the bot up. Say "Hi {name}!" and Sara reads "Hi Sara!" {word1} {word2} {word3} The words typed after a command. If someone types !guess 7 please, then {word1} is "7" and {word2} is "please". {words} ALL the words after the command, together. {line} The whole line the person typed. {memory:coins} What is written in the memory called "coins" (works for any memory name). {mymemory:coins} That person's OWN "coins" memory. Sara's coins, when Sara asked. See Memory below. {rand:1-6} A fresh random number from 1 to 6, different every time. Any range works: {rand:1-100}. {pick:red|green|blue} A fresh random choice from your list. Split the choices with the | line. {bot} Your bot's own name. {room} The room's name. {humans} How many people are in the room (bots not counted). {time} The time right now (UTC).

In the editor there is a ✨ button next to every say box - it drops these in for you so you never have to remember the spelling.

Memory (how games work)

A memory is a little labelled box the bot keeps. You invent the label. There are two kinds, and the difference matters:

shared by everyone ONE box for the whole room. Good for: the answer to the current quiz question, the bot's last rock-paper-scissors throw, a group score. each person their own EVERY person gets their own box with the same label. Sara's "coins" and Omar's "coins" are different boxes. Good for: points, coins, personal bests, "have I welcomed this person before".

Memories start at 0, stick around while your bot is deployed, and are saved with your bot. In the Test room, the "What it remembers" panel shows them changing live.

The ONLY IF part (checks)

Checks make bots smart. A rule only runs when EVERY check passes. Each check compares two things: is exactly, is not, is bigger than, is smaller than, or contains.

"Is exactly" means exactly (capital letters don't matter, but spelling does). Use magic words in either side:

WHEN someone types !buy ONLY IF {mymemory:coins} is bigger than 9 DO count up coins by -10, then say "Sold! You have {mymemory:coins} coins left."

Want an "otherwise"? Make a second rule for the same command with the opposite check ("is smaller than 10") that says "You can't afford it yet!"

Recipes (how do I make...)

A quiz with points

  1. Rule 1: WHEN someone types !quiz → DO say "What has keys but can't open doors? Answer with !answer"
  2. Rule 2: WHEN someone types !answer → ONLY IF {word1} is exactly piano → DO count up points (each person their own) by 1, then say "Right! {name} has {mymemory:points} points 🏆"
  3. Rule 3: WHEN someone types !answer → ONLY IF {word1} is not piano → DO say "Nope, try again!"

A secret password door

  1. Rule 1: WHEN someone types !door → ONLY IF {word1} is exactly banana → DO say "🚪 The door swings open for {name}..."
  2. Rule 2: WHEN someone types !door → ONLY IF {word1} is not banana → DO say "Wrong password."

A shop

Give people coins with a command (count up), check coins with "is bigger than" before selling (see the ONLY IF example above), and show a menu with a plain say rule for !shop. Open the ready-made Fishing bot - it is a whole tiny economy you can copy.

A bot that argues back differently every time

One rule: WHEN someone says the bot's name → DO say {pick:Who, me?|I heard that.|Leave me out of this.|{name}, please.}

A reminder bot

WHEN every 10 minutes → DO say "💧 Water break! It is {time}." (Test it with the "Ring the timers" button - no waiting.)

"My bot isn't answering!"

Wrong start Commands must START the line. Put !roll on its own line. Too fast The bot reads your line after it stops changing for ~2 seconds. Give it a beat. (The Test room answers instantly.) Spelling "is exactly" means exactly. !fish and !fishing are different commands. Curly brackets If your bot literally says "{wrod1}", the magic word is misspelled - the bot leaves typos visible so you can find them. Use the ✨ button. Bot pace Bots take a short breath between messages and can't spam. If you queue 10 says, they come out one at a time. It vanished Your bot goes home when: you leave Talkomatic, its room empties, the room votes it out, or a moderator stops it.

The rules (read this once)

Bots follow the same rules people do. Everything they say goes through the same filter. A room can vote a bot out. Two bots per room, one running bot per person, and whatever your bot does counts as YOU doing it - so make things people will like having around. Moderators can see every bot and its owner, and can turn any bot off.

For coders: the bot API

Already writing Node or Python? You can skip the editor and drive a bot with real code. Your program gets an ordinary seat with a BOT badge, and follows the same rules: 2 bots per room, the word filter, and moderation.

1. Get a token

Tokens are requested from code, not from a browser (that is deliberate). Three per IP, valid 30 days: 

curl -X POST /api/v1/bot-tokens/request \
  -H "User-Agent: my-bot/1.0"

2. Connect and join

// npm install socket.io-client
const { io } = require("socket.io-client");

const socket = io("", {
  transports: ["websocket"],
  auth: { token: "YOUR_TOKEN" },
});

socket.on("connect", () => {
  socket.emit("join lobby", { username: "MarketBot", location: "Bot" });
});

socket.on("signin status", (s) => {
  if (s.isSignedIn) socket.emit("join room", { roomId: "123456" });
});

socket.on("room joined", (d) => console.log("seated in", d.roomName));

3. Read the room, type replies

// Everyone's textbox, live. data.diff.text is their full box.
socket.on("chat update", (data) => {
  const line = (data.diff?.text || "").split("\n").pop().trim();
  if (line === "!price") say(socket, "Fish is 3 coins today.");
});

// Your own box: send the full text (send it in pieces to "type").
function say(socket, text) {
  socket.emit("chat update", {
    diff: { type: "full-replace", text },
  });
}

The same thing in Python

# pip install "python-socketio[client]"
import socketio

sio = socketio.Client()

@sio.event
def connect():
    sio.emit("join lobby", {"username": "MarketBot", "location": "Bot"})

@sio.on("signin status")
def signin(s):
    if s.get("isSignedIn"):
        sio.emit("join room", {"roomId": "123456"})

@sio.on("chat update")
def chat(data):
    line = (data.get("diff", {}).get("text") or "").split("\n")[-1].strip()
    if line == "!price":
        sio.emit("chat update", {"diff": {"type": "full-replace", "text": "Fish is 3 coins today."}})

sio.connect("", auth={"token": "YOUR_TOKEN"},
            transports=["websocket"])
sio.wait()

Worth knowing

Useful events: room joined, user joined, user left, chat update, kicked, error. Leave with leave room. Bot traffic has its own rate limits; hammering the socket gets events dropped, and staff can disconnect any bot at any time. Rooms are 6-digit ids - the number in the room page URL.
