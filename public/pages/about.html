About Talkomatic, the World's First Chat Room

Talkomatic is a chat room with one unusual quality: you see what everyone is typing as they type it, letter by letter, instead of waiting for them to press send. You watch people pause, backspace, and change their minds. It makes a conversation feel less like posting and more like talking.

Talkomatic is the world's first multi-user chat room, written in 1973 on the PLATO system, years before CompuServe's CB Simulator (1980) and IRC (1988). This is that same idea, still running, free and open to anyone with a browser.

There is no sign-up, no download and no ads. Pick a name and start talking.

The History of Talkomatic

1973

The First Chat Room

Created by Doug Brown and David Woolley, two students working on the PLATO system at the University of Illinois. Doug built the first prototype; David extended it with multiple channels and the ability to make a conversation private.

1970s

The PLATO Era

PLATO (Programmed Logic for Automatic Teaching Operations) was a computer-based education system that grew into the first real online community. Alongside Talkomatic it carried message boards, email, instant messaging and multiplayer games, most of them years ahead of their better-known successors.

2013-2014

Rebuilt for the Web

Work on a web version began in September 2013, and the first browser-to-browser chat took place on 11 March 2014. The WebSocket standard finally made it possible to send every keystroke live without any special software.

2014-2015

Private Rooms and Accounts

Version 2.0 added private rooms in May 2014. Version 3.0 followed in July 2015 with social login, making it quicker to get in.

2018

Kept Alive

Steve Zoppi re-hosted and updated the service to version 3.2, and with Ray Ozzie's support it ran across several domains.

March 2024

The Original Goes Offline

After a decade on the web, the original service shut down.

June 2024

Talkomatic Classic

Talkomatic returned at talkomatic.co as a free, open-source project so that the first chat room ever made would not simply disappear. It is run by its community rather than owned by a company, and the code is public for anyone to read, host or improve.

What Makes Talkomatic Different

Live, Letter by Letter

Every keystroke appears the moment you make it. No send button, no waiting, no typing indicator standing in for the real thing.

Everyone Gets a Space

The screen is split so each person has their own area. You can follow several people at once without a wall of messages fighting for order.

No Account Needed

No email, no password, no profile to fill in. Choose a display name in the lobby and you are in.

Public, Semi-Private or Private

List a room for anyone to join, put a 6-digit code on it, or keep it unlisted and hand out the link yourself.

Nothing Is Logged

What you type is held in memory while you are in the room and never written to a database. When it leaves the screen it is gone.

Make It Yours

Swap the whole site's look with community themes, or build your own colour scheme in the visual editor and share it.

More Than Talking

Rooms come with minigames and a shared drawing board, so there is something to do when the conversation pauses.

Build a Bot

Make a chat bot with no code at all using the block editor, or drive one yourself through the bot API.

Rules in the Open

The community rules and the moderator rules are both published in the lobby, so anyone can read what staff may and may not do.

Works Anywhere

Desktop, tablet or phone, in any modern browser. Nothing to install and nothing to update.

Open Source, Community Run

No company owns it, no ads, no tracking. The code is public and the project is kept going by the people who use it.

A Piece of History

You are using the oldest idea in online chat, still working the way it did in 1973.

How Talkomatic Is Built

Talkomatic is written entirely in JavaScript. The server runs on Node.js and uses Socket.IO to hold the live connection that carries every keystroke. The client is plain browser JavaScript with no framework and no build step, which is part of why the page loads as quickly as it does. The source is open for anyone to read, host or improve.

Frequently Asked Questions

What is Talkomatic?

Talkomatic is a chat room where you see what other people are typing as they type it, letter by letter, instead of waiting for them to press send. It was created in 1973 on the PLATO system and was the world's first multi-user chat room. It runs free in any modern browser.

Do I need an account to use Talkomatic?

No. There is no sign-up, no email and no password. You choose a display name in the lobby and start chatting. Talkomatic is anonymous by design.

Was Talkomatic really the first chat room?

Yes. Talkomatic was written in 1973 by Doug Brown and David Woolley on the PLATO system at the University of Illinois. It predates CompuServe's CB Simulator (1980) and IRC (1988), making it the earliest known multi-user chat room.

Does Talkomatic save chat history?

No. What you type is held in memory only while you are in the room and is never written to a database or a log file. Once it leaves the screen it is gone, and nobody can retrieve it afterwards.

Which browsers and devices does Talkomatic work on?

Any current version of Chrome, Firefox, Safari, Edge or a similar modern browser, on desktop, tablet or phone. JavaScript and cookies need to be enabled. Internet Explorer is not supported. On a phone the on-screen keyboard can cover part of the room, so a physical keyboard or voice input is more comfortable if you have one.

What kinds of rooms can I make?

Public rooms are listed in the lobby for anyone to join. Semi-private rooms are listed but need a 6-digit access code. Private rooms are not listed at all and are reached by sharing the room link. You can also choose whether people sit side by side or stacked.

Who owns and runs Talkomatic?

Talkomatic Classic is an open-source, community-run project. It is not owned by a company, carries no ads and no tracking, and its moderation rules are published publicly so anyone can read what moderators may and may not do. Ideas and bug reports go on the suggestion board in the lobby, where everyone can vote on them.

How is Talkomatic built?

Talkomatic is written entirely in JavaScript. The server runs on Node.js with Socket.IO handling the real-time connection, and the client is plain browser JavaScript with no framework and no build step. The source is open.

Can I embed a Talkomatic room in my own website?

Yes. Use an iframe pointing at https://talkomatic.co to embed the lobby, or paste a room's own link, copied from the invite bar inside that room, to embed a single room.
